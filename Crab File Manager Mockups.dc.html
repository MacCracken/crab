0Brief, assumptions & the system
What I read

crab is a dual-pane, local-first file manager for AGNOS. It is a view onto a shared memory substrate — semantic find, duplicate detection, auto-tagging — not an app with a bolted-on assistant. The repo is a docs scaffold: no UI source, so nothing here is a recreation.

Mascot Bueller 🦀 gets one quiet home: the status bar. Deadpan, rare, never loud.

Assumptions

Platform-neutral chrome — no OS-specific traffic lights or ribbon. Small window collapses the sidebar into a drawer overlay.

The compositor owns theming. crab ships no theme switcher and no palette of its own; it reads surface, text and accent from aethersafha and declares only which parts of the UI accent is permitted to tint. Light and dark shells here are two compositor states, not two crab settings.

Fidelity: wireframe-plus. Real structure, real density, real copy; placeholder icons and striped image slots. Static — nothing is wired.

The system

Type: Barlow for UI, JetBrains Mono for paths, sizes and anything a filesystem literally owns.

Surface: green-grey neutrals, hairline 1px seams, no shadows inside the app. Density: 28px rows full-screen, 34px touch rows small.

Icons: geometric chips with mono extension labels; images are striped placeholders. Real icon set to be dropped in.

Open questions

Does the second pane ever leave? A dual-pane app in a 420px window is one pane with a switcher — worth confirming that's acceptable rather than blocking the small size.

Which accent roles does the compositor actually hand over — one accent, or accent + on-accent + a hover step? That decides whether selected rows can carry white text.

Is semantic search a view (1b) or a mode over any view? Cheapest to build as a view; better to use as a mode.

21a + 1b shell, 1c columns & preview — and the crab is the menu button

Same layout twice, once per compositor palette. Pane A is columns, pane B is the preview; the dual pane survives as a tab pair so a 420px window can drop to one. Clicking 🦀 toggles the File / Edit / Go menu row — shown collapsed in 2a, revealed in 2b. Collapsed is the default: the menu is a power surface, and the crab earns its place in the chrome by being the door to it.
